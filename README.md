# 📊 Business Intelligence Portfolio - Power BI Projects

## 🏢 About This Repository
This repository contains a collection of Business Intelligence projects demonstrating end-to-end data analysis capabilities using Power BI. Each project covers different aspects of the BI workflow: from data preparation and cleaning to visualization and dashboard creation.

---

## 📁 Projects Overview

### 1. **AfriRetail Data Preparation & Analytics**
**📍 Project Type:** Data Engineering & ETL  
**🎯 Focus:** Power Query data transformation, data quality, dimensional modeling  
**📊 Status:** COMPLETED ✅

**Business Context:**  
AfriRetail Ltd, a mid-sized retail company operating across East Africa, needed clean, analysis-ready data for sales reporting. Raw data from multiple branches had inconsistencies, missing values, and formatting issues preventing accurate reporting.

**Key Deliverables:**
- ✅ Data ingestion from multiple sources (CSV, Excel)
- ✅ Comprehensive data quality assessment and profiling
- ✅ Text standardization and missing value handling
- ✅ Data integration through Power Query merges
- ✅ Business metric calculations (sales, profit, margins)
- ✅ Star schema dimensional modeling
- ✅ Data governance and load control implementation

**Files:**
- `DSA3050A_PowerQuery_Lab.pbix` - Complete Power BI solution
- `powerquery_Screenshots/` - Documentation of all transformation steps
- `PowerQuery-Lab.md`-specific readme documenting steps of this powerquery lab

### 2. **Sales Performance Dashboard**
